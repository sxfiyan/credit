# CorpScore AI

### Automated Corporate Credit Scoring & Loan Default Predictive Engine

CorpScore AI is a modern, high-fidelity Single-Page Application (SPA) designed to automate corporate credit underwriting, evaluate default risks, and simulate macroeconomic stress scenarios. It blends empirical credit scoring methodologies (Altman Z-Score) with quantitative structural credit models (Merton Distance to Default) and a weighted financial ratios index to support credit decisions.

---

## 🌟 Key Features

- **Blended Risk Engine**: Evaluates corporate credit risk using three separate methodologies:
  - **Altman Z-Score**: Dynamically calculated for manufacturing (`Z = 1.2*X1 + 1.4*X2 + 3.3*X3 + 0.6*X4 + 0.999*X5`) and non-manufacturing/service sectors (`Z' = 6.56*X1 + 3.26*X2 + 6.72*X3 + 1.05*X4`).
  - **Merton Structural Model**: Estimates corporate Distance-to-Default (D2D in standard deviations $\sigma$) and default probabilities using market cap, total liabilities, and asset volatility inputs.
  - **Weighted Credit Index**: A 100-point scoring scale mapping Liquidity, Leverage, Profitability, Solvency, and Efficiency ratios against industry benchmarks to assign credit grades (AAA to D).
- **Dynamic Stress-Testing**: Sliders to apply macro-economic shocks (Revenue downturns, interest rate spikes, and collateral haircuts) to see real-time shifts in rating grades, cash flows, and loan approvals.
- **Lending Decision Support**: Calculates Debt Service Coverage Ratio (DSCR), Loan-to-Value (LTV), recommended risk spreads/interest rates, and maximum borrowing capacity.
- **Portfolio Management**: Local database (`localStorage`) to search, filter, analyze, and delete previously assessed companies.
- **Interactive Visualizations**: Radar charts for ratio benchmarking and radial default probability gauges powered by Chart.js.
- **Automated Credit Memo Exports**: Standard-compliant print styles formatting detailed risk report dashboards as multi-page corporate PDFs.

## 📂 Project Structure

- `index.html`: The user interface structure and SPA views.
- `index.css`: Design tokens, responsive grids, glassmorphism aesthetics, dark mode styles, and print-ready formats.
- `app.js`: Financial scoring models, Chart.js integrations, portfolio management, and slider handlers.
- `mockData.js`: Preconfigured corporate profiles for instant evaluation.
- `verify.js`: Node.js mathematical verification tests.
- `package.json`: Dependency declarations and execution scripts.

## 🚀 Installation & Local Development

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed on your system.

### Running the App
1. Clone this repository (or navigate to the project directory):
   ```bash
   cd 20241CCS0144
   ```
2. Launch the local development server:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to the local address displayed in the terminal:
   ```
   http://localhost:3000
   ```

### Running Calculations Verifications
To run the automated verification script and prove mathematical calculations correctness:
```bash
node verify.js
```
